# Agent Handoff

This repository contains a completed, research-only investigation of nine downloaded MCC/minigame maps.

**Start here:** `game-plugins/research/existing_maps/README.md`
**Full agent handoff:** `game-plugins/research/existing_maps/AGENTS.md`

The pack includes per-map dossiers, command/container inventories, 700 image files, copied resource-pack references, a cross-map synthesis, and an independent QA audit. All nine worlds are imported on the local `25580` review server.

Important scope note: the Kessler Run and Sunset Skyway map generators, the Nocturne Orrery core geometry, and the dome previews are **not** committed. Do not add them to a commit unless the owner explicitly asks. The Decision Dome vote engine is committed separately and does not include the core dome geometry.

Do not start a build, paste, registry change or world edit from this research pack without an explicit owner instruction.
