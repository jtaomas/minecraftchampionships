# Reference image pack — open these files directly

All images are full-resolution stills saved under `frames/pack/`. The filenames
in the tables below are relative to that `pack/` folder. They are
reference material for the block-location builder, not assets to copy into the
server resource pack. Wiki images are Tier 1 (MCC wiki); VOD frames are Tier 1
(official event footage). Timestamps are `event VOD` time, not clip time.

## Caveats

- The poster is a palette graphic, not a plan; it gives exact blocks but not
  positions. Positions come from the VOD stills and are approximate (M/L).
- `10` and `20` show the same ring from different heights; label text is
  readable but the ring is wider than one frame, so no single still shows all
  16 colour bays.
- MCC 19 stills are used **only** for the Snow island, which existed for one
  event. Do not treat snow as part of the standard palette.
