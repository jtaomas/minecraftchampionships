**Target:** the festive MCC event hub in `reference/hub_festive.png` — central Decision Dome with crown, red bow, `MCC CHAMPIONSHIP` clock, `THE CHAMPS` mountain, giant blue globe, game portal buildings, snow, water, paths and terraces.

**Base world:** `mcc_lobby_official` on the 25580 review server.
**Build site:** `C = 5000, 120, 5000` in that world. New chunks, far from the imported official hub.
**Owner instruction:** personal use, closest one-to-one replica possible.

## Build method

No WorldEdit console shapes. Build with a **datapack function generated by Python**, or a block list plus function writer.

- Write only under `game-plugins/research/lobby_replica/build/<your-id>/`.
- Generate `blocks.csv` or a Python generator, then `.mcfunction` files.
- Use `setblock` for detail and `fill` for large solid masses.
- Split functions into chunks of about 8,000 commands.
- Do not execute anything on the server; the coordinator runs the final functions.
- Do not edit `plugin-src/`, game code, the world, or another agent's folder.
- Do not use Bedrock/Noxcrew custom blocks; Java 1.21.1 vanilla only.
- Keep each section under about 30,000 blocks.
